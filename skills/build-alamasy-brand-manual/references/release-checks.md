# Release gate — الاماسي Brand Operating Manual

Record **Pass / Fail / Not tested** plus evidence for each item. "Not tested" never means pass.

1. Current repository commit and owner-approved facts recorded; proposed rules clearly distinguish themselves from existing implementation.
2. Arabic name consistent on site/metadata/receipt/marketing; registered or Latin variant confirmed before external print.
3. Logo vector master exports without dependency breakage; horizontal/compact/reverse/mono, clearspace and minimum-size proof pass.
4. Brand and semantic colors tokenized; all foreground/background combinations checked for 4.5:1 body, 3:1 large text/essential UI; print colors proofed with vendor.
5. Arabic font weights/rights available; mixed-direction IDs, phone numbers, currency and file names correct; copy fits 320px and 200% zoom.
6. RTL order of navigation, keyboard focus, controls and layout valid on mobile/tablet/desktop; no clipped content.
7. File intake, price calculation, order status, WhatsApp handoff and receipts specify default/loading/error/empty/success/disabled/cancelled states where applicable.
8. Each photograph/video has provenance, use permission and truthful caption; illustrative assets visibly differentiated from real branch evidence.
9. Copy makes no unverified endorsements, accreditation, delivery promises, service fees or confirmed-order claims; privacy and customer-file handling reviewed.
10. Printed samples meet bleed, margin, PPI, font, PDF/export and vendor proof requirements; client artwork stays unaltered.
11. At least one brand-consistent example for storefront, receipt, proof slip, pickup label, price board, support message and one real product campaign.
12. Rule IDs unique and not duplicated; output assets, implementation path map, accountable approver, version, date and change-control record present.

### Mandatory unresolved-assets report

Explicitly identify missing final vector artwork; verified registered/English name; authentic store photography and rights; clearance-related approvals; live business facts; trustworthy order/notification events; and printer ICC/proof settings. Do not declare the manual "ready without modification" while a material release item is unverified.
